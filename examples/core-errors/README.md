# Пример для @atls/core-errors

Показываем, как жить с `DomainError`: наследуемся, пробрасываем полезные поля и не забываем нормальные фабрики для доменных косяков.

Копируешь заготовку из `src/index.ts`, чтобы не писать очередной кастомный `Error` с потерянным стеком. Никаких глобальных зависимостей — чистый домен.
